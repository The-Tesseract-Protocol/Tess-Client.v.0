# Foreword

> “Alone we can do so little; together we can do so much” - Helen Keller

\
As **Denelle Dixon** aptly framed it "_the real question is not whether established payment systems or emerging protocols will “win,” but how they will work together to serve a global economy that demands both institutional accountability and universal access_." [<sub>_blog_</sub>](https://stellar.org/blog/foundation-news/the-interoperability-imperative-how-traditional-payment-networks-and-open-protocols-will-finally-work-together)

The same first principle applies to confidentiality. Institutions are not asking for total anonymity or an escape from oversight. Their requirement is more precise,  \
\
"_to remove unnecessary and harmful visibility into operational flows, while preserving full compliance, auditability, and regulatory assurance"_. <br>

At Tesseract (_Tess_ ) we propose a solution to all the needs for institutions to work with public ledgers without any compromises.
